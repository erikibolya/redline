Connect to a server

RedLine runs on this computer by default. Use a server when the agents and repositories live on another machine (Unraid, NAS, WSL) and reviews must stay available while this computer is off.

The address printed by the container: http://<host>:8788

On the server: docker logs redline | grep -i token. The token is also in the app's start page under “Connect an agent”.
